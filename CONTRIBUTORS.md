# Contributors

Didacta existe gracias a la gente que lo construye y lo prueba.

## Equipo

- **VA360 LABS S.L.** — creadores y mantenedores ([didacta.io](https://didacta.io))

## Colaboraciones

Las contribuciones externas se reconocen aquí a partir de la primera versión
pública. Si has enviado un PR mergeado y no apareces, ábrenos un issue o
añádete en tu siguiente PR (nombre o alias + enlace, orden alfabético).

Para contribuir, lee [CONTRIBUTING.md](CONTRIBUTING.md) — recuerda que el
proyecto requiere aceptar el CLA y que el código es fair-code bajo la
[Didacta Sustainable Use License](LICENSE).

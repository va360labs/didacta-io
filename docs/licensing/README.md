## Position statement

Didacta is **fair-code** and **source-available**. We are **not** open source under the OSI definition.

We adopt this model deliberately, following the same approach as n8n.io. The goals are:

1. Maximum transparency — you can read every line of code.
2. Free internal use — evaluate, develop, train your own people without paying.
3. Sustainable business — paid distribution requires a commercial agreement, which funds the project.
4. Community — contributions are welcome under the project's license terms.

For a deeper discussion of fair-code, see [faircode.io](https://faircode.io/).

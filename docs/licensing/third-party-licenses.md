# Third-party licenses inventory

> Generated by `pnpm tsx scripts/license-check.ts`.
> Last updated: pending first run.

This file lists all third-party dependencies of Didacta and their licenses.

## Policy

| License family | Allowed | Notes |
|----------------|:-------:|-------|
| MIT, Apache 2.0, BSD, ISC | ✅ | Preferred |
| LGPL | ✅ | If linked dynamically |
| GPL / AGPL | ❌ | Forbidden in distributed code |
| MPL 2.0 | ⚠️ | Case by case — generally OK if not modifying |
| Custom non-OSI | ⚠️ | Requires ADR before adopting |

## How to regenerate this file

```bash
pnpm tsx scripts/license-check.ts --output docs/licensing/third-party-licenses.md
```

## Inventory

> Run the script above to populate. CI rejects PRs that introduce dependencies with forbidden licenses.
